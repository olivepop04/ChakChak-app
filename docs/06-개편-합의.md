## 문구가 이렇게 바뀝니다

모집 현황은 **조사를 생략**하는 방식으로 통일합니다. "40포**이** 더 필요해요" 같은
오타가 원천 차단되고, kg·EA·ml 같은 영문 단위에서도 문장이 자연스럽습니다.

| 상황 | 표시 |
|---|---|
| 3~5명 모집, 지금 2명 | `2 / 3~5명` · 목표까지 1명 남았어요 |
| 3~5명 모집, 지금 3명 | `3 / 3~5명` · 최소 인원을 채웠어요. 2명 더 함께할 수 있어요 |
| 3~5명 모집, 다 참 | `5 / 3~5명` · 모집이 완료됐어요. 다른 방식으로 참여해주세요 |
| 최소 10명, 지금 4명 | 목표까지 6명 남았어요 |
| 최소 10명 넘음 | 더 많은 크루가 참여할수록 좋아요 |

시간은 **24시간제로 통일**합니다 (14:00–17:00).
알림은 문서 명세대로 문구를 전면 교체하고, **나가기 알림 1종이 추가되어 7종**이 됩니다.

## 작업 순서 — 이 순서를 지켜야 두 번 일하지 않습니다

```
0. 전원이 이 문서를 읽고 OK          ← 지금 여기
1. 민호 — 문구 일괄 교체 (반나절)     이름·호스트/크루·모집 문구·24시간제·알림
2. 민호 — 스키마 한 번에 (반나절)     알림 설정·참여 시간·장소명·게시판 구분 등
3. 민호가 "시작하세요" 신호
4. 각자 — 자기 화면 작업 (1~2일)      역할 문서의 할 일 목록대로
5. 개발 A — Discover 고도화 (이틀)    다른 작업과 겹치지 않아 병행 가능
```

**왜 민호가 먼저인가:** 문구와 스키마는 모든 화면에 깔리는 바닥입니다.
바닥이 바뀌기 전에 각자 시작하면, 옛날 문구 위에서 작업한 걸 다시 고치게 됩니다.

단, 역할 문서에 **"지금 바로 할 수 있는 것"** 으로 표시된 항목은 신호 전에 시작해도 됩니다.
