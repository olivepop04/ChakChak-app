# Discover 고정 5문항 추천 흐름 구현 계획

**목표:** Discover가 네 번째 답변 뒤 질문 문장을 남기지 않고, 사용자 선택 경로에 맞는 질문 5개의 답변을 모두 받은 다음 추천하도록 변경합니다.

**구현 원칙:** 후보 조회, 점수 계산, AI 추천 이유 생성 구조는 유지합니다. 질문의 순서와 추천 전환 시점만 서버 코드가 결정하고, AI는 정해진 질문을 자연스럽게 표현하는 역할만 맡습니다.

## 작업 순서

1. `tests/discover-interview.test.ts`에 다음 회귀 테스트를 먼저 추가합니다.
   - 첫 질문은 항상 재능 활용 여부입니다.
   - 재능 활용을 선택하면 두 번째로 재능을 묻습니다.
   - 재능 미사용을 선택하면 재능 대신 참여 방식을 묻습니다.
   - 신규 회원도 분야 선호 질문을 포함합니다.
   - 네 번 답했을 때는 추천하지 않고 다섯 번 답했을 때만 추천합니다.
   - 추천 전환 시 AI가 만든 다음 질문 문장을 고정 추천 안내 문장으로 바꿉니다.
2. 새 테스트가 기존 코드에서 실패하는지 확인합니다.
3. `app/api/ai/discover/interview.ts`의 질문 상태와 추천 전환 규칙을 최소 수정합니다.
4. `app/api/ai/discover/route.ts`에서 질문 순서를 서버가 고정하고, 다섯 번째 답변 뒤에는 고정 안내 문장만 반환하도록 수정합니다.
5. `components/action/DiscoverChat.tsx`의 최대 답변 수 안내를 5개로 맞춥니다.
6. 대상 테스트, 전체 테스트, 타입 검사, 린트, 빌드와 Git diff 검사를 실행합니다.
7. 검증이 끝난 파일만 커밋하고 브랜치를 푸시한 뒤 `dev` 대상 PR을 생성합니다.
