**이 자리가 가장 중요한 이유:** 공통 컴포넌트를 한 사람이 만들어야 화면마다 버튼 모양이 달라지는 걸 막을 수 있습니다. 그리고 Home과 Detail은 **발표에서 가장 오래 보이는 화면**입니다.

목업 11개가 이미 HTML로 있으니, **그걸 React 컴포넌트로 옮기는 일**이 대부분입니다.

### Button 예시 — 이 형태로 만들어 주세요

```tsx
// components/ui/Button.tsx
import { cn } from '@/lib/utils/cn';

interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'danger';
  size?: 'sm' | 'md';
  fullWidth?: boolean;
}

export function Button({
  variant = 'primary', size = 'md', fullWidth, className, ...props
}: ButtonProps) {
  return (
    <button
      className={cn(
        'inline-flex items-center justify-center rounded-xl font-semibold transition',
        'disabled:cursor-not-allowed disabled:opacity-40',
        size === 'sm' ? 'h-9 px-3 text-[13px]' : 'h-12 px-5 text-[15px]',
        variant === 'primary' && 'bg-neutral-900 text-white active:bg-neutral-700',
        variant === 'secondary' && 'border border-neutral-300 bg-white text-neutral-800',
        variant === 'danger' && 'border border-red-200 bg-red-50 text-red-600',
        fullWidth && 'w-full',
        className,
      )}
      {...props}
    />
  );
}
```

**`disabled` 상태를 반드시 넣어주세요.** 참여 버튼이 "모집 완료"일 때 눌리면 안 됩니다.

### LikeButton 예시 — 낙관적 업데이트

버튼은 **누르는 즉시 반응**해야 합니다. 서버 응답을 기다리면 느리게 느껴집니다.

```tsx
'use client';
import { useState } from 'react';
import { createClient } from '@/lib/supabase/client';
import { toggleLike } from '@/lib/mutations';

export function LikeButton({
  actionId, initialLiked, initialCount,
}: { actionId: string; initialLiked: boolean; initialCount: number }) {
  const [liked, setLiked] = useState(initialLiked);
  const [count, setCount] = useState(initialCount);
  const [busy, setBusy] = useState(false);

  async function handleClick() {
    if (busy) return;
    setBusy(true);

    // 1) 화면을 먼저 바꾼다
    const prevLiked = liked, prevCount = count;
    setLiked(!liked);
    setCount(liked ? count - 1 : count + 1);

    // 2) 서버에 보낸다
    const res = await toggleLike(createClient(), actionId, prevLiked);

    // 3) 실패하면 되돌린다
    if (!res.ok) {
      setLiked(prevLiked);
      setCount(prevCount);
      alert(res.message);   // 비로그인이면 "로그인이 필요합니다."
    }
    setBusy(false);
  }

  return (
    <button onClick={handleClick} aria-pressed={liked} className="...">
      {liked ? '♥' : '♡'} {count}
    </button>
  );
}
```

`SaveButton`, `FollowButton`도 **똑같은 구조**입니다. `toggleSave`, `toggleFollow`로 바꾸기만 하면 됩니다.

## 2주차 — Home 피드

**주소:** `/`
**파일:** `app/page.tsx` (지금은 확인용 임시 화면입니다. 갈아엎으세요)
**목업:** `01.good_home_for_you_v02.html`

### 데이터

```tsx
import { createClient } from '@/lib/supabase/server';
import { getActionFeed } from '@/lib/queries/actions';
import { ActionCard } from '@/components/ui/ActionCard';

export default async function HomePage() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();

  const actions = await getActionFeed(supabase, {
    viewerId: user?.id ?? null,
    limit: 20,
  });

  return (
    <main className="pb-20">
      {/* 헤더 */}
      <div className="flex flex-col gap-4 px-5 py-4">
        {actions.map((a) => <ActionCard key={a.id} action={a} />)}
      </div>
    </main>
  );
}
```

`getActionFeed`는 **ACTIVE 액션만** 돌려줍니다. DRAFT나 종료된 건 안 나옵니다.

### 중요 — 비회원도 볼 수 있어야 합니다

Home과 Action Detail은 **로그인 없이 열립니다.** 그래서:

- `user`가 `null`일 수 있습니다. `user?.id ?? null`로 넘기세요.
- Like/Save 버튼은 보이되, 누르면 `"로그인이 필요합니다."`가 뜹니다 (mutations가 처리)
- 하단 탭에서 DISCOVER 등을 누르면 로그인 화면으로 갑니다 (middleware가 처리)

**`user!`처럼 강제로 단언하지 마세요.** 비회원이 열면 터집니다.

## 3주차 — Action Detail

**주소:** `/action/[id]`
**파일:** `app/action/[id]/page.tsx`
**목업:** `02.GOOD_create_detail_result_v07.html` (가운데 Detail 부분)

### 데이터

```tsx
import { notFound } from 'next/navigation';
import { getActionDetail } from '@/lib/queries/actions';

export default async function ActionDetailPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;                    // ★ await 필수
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();

  const action = await getActionDetail(supabase, id, user?.id ?? null);
  if (!action) notFound();
  // ...
}
```

`getActionDetail`이 돌려주는 것 중 화면 분기에 쓰는 값:

| 필드 | 용도 |
|---|---|
| `isOwner` | 내가 만든 액션인가 → 참여 버튼 대신 관리 버튼 |
| `myParticipation` | `null`이면 미참여, `'BEFORE_ACTION'`이면 이미 참여 중 |
| `recruitClosed` | 모집 마감 시각이 지났는가 |
| `status` | ACTIVE / ENDED / COMPLETED / CANCELLED |
| `items` | 모집 항목 + 현재 진행 상황 |

### 화면 구성

```
[이미지 캐러셀]  ← imageUrls 여러 장, thumbnailIndex가 첫 장
카테고리 · 제목
(아바타) @닉네임  [팔로우]
소개 텍스트

── 모집 현황 ──
QuotaProgress × N개

── 일정 & 장소 ──
8월 30일 14:00–17:00
서울 성동구 ○○로 12   [주소 복사] [지도에서 보기]

── 안내사항 ──
notice

[♥ 좋아요] [🔖 저장] [공유]

────────────────
[참여하기]   ← 하단 고정
```

### 모집 현황 — 이미 만들어져 있습니다

```tsx
import { QuotaProgress } from '@/components/action/QuotaProgress';

{action.items.map((item) => (
  <QuotaProgress
    key={item.id}
    item={item}
    current={item.currentCount}
    detailed
    conditionName={item.conditionName}
  />
))}
```

**숫자를 직접 조합하지 마세요.** 최소 인원형은 퍼센트를 안 쓰고, 정해진 인원형은 최소를 넘기면 분모가 바뀝니다. 이 규칙이 컴포넌트 안에 들어 있습니다.

### 하단 버튼 분기 — 이 표대로

| 조건 | 버튼 |
|---|---|
| 비회원 | `참여하기` → 누르면 로그인으로 (middleware가 처리) |
| `isOwner` | `수정하기` · `취소하기` (ACTIVE일 때) |
| `myParticipation !== null` | `CREW CHAT으로 가기` |
| `status !== 'ACTIVE'` | 비활성 + `모집이 종료되었어요` |
| `recruitClosed` | 비활성 + `모집이 마감되었어요` |
| 모든 항목이 `isFull` | 비활성 + `모집이 완료되었어요` |
| 그 외 | `참여하기` → `/action/{id}/join` |

### 주소 복사 & 지도

```tsx
'use client';
await navigator.clipboard.writeText(action.address);
// 지도: 외부 링크로 열기
```

### CANCELLED 상태

취소된 액션은 **취소 사유를 눈에 띄게** 보여줘야 합니다.

```tsx
{action.status === 'CANCELLED' && (
  <div className="rounded-xl border border-red-200 bg-red-50 p-4">
    <p className="text-sm font-semibold text-red-800">이 액션은 취소되었어요</p>
    <p className="mt-1 text-sm text-red-700">{action.cancelReason}</p>
  </div>
)}
```

## 계속 — 시각적 통일

3주차 이후에는 **다른 사람이 만든 화면을 돌아보며 통일**하는 일이 주 업무가 됩니다.

체크할 것:

- 같은 의미의 버튼이 화면마다 다르게 생기지 않았는가
- 여백이 들쭉날쭉하지 않은가
- 빈 상태 화면이 다 있는가
- 글자 크기가 제각각이 아닌가

**직접 고치기 전에 담당자에게 알려주세요.** 같은 파일을 동시에 고치면 충돌이 납니다.
