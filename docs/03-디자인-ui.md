## ⚠️ 절대 바꾸면 안 되는 것

**`ActionCard`의 props 이름과 개수.** 다섯 화면이 이 컴포넌트를 씁니다.

```tsx
<ActionCard action={...} showStatus footer={...} />
```

보이는 모습(색·간격·타이포·레이아웃)은 **마음껏 바꾸셔도 됩니다.** props만 그대로 두세요.

**`QuotaProgress`의 계산 로직.** 모집 수량 표시 규칙이 들어 있습니다.

```tsx
// 이 컴포넌트 안의 getQuotaState() 호출부는 건드리지 마세요
// className 과 마크업 구조만 바꾸세요
```

왜냐하면 규칙이 두 가지로 갈리기 때문입니다.

```
최소 10명형   →  15명 / 10명 ·  퍼센트를 쓰지 않음 (150%는 의미가 없음)
3~5명형       →  4 / 3~5명  ·  퍼센트를 씀
              →  분모는 "3~5명" 으로 끝까지 고정. 정확히 3명이면 "3명"
```

숫자를 직접 조합하면 이 규칙이 깨집니다.

> ### 🚧 시작하기 전에 꼭 읽어주세요 — 카드 전체가 링크입니다
>
> 지금 `ActionCard` 는 **이미지부터 통계까지 전부 하나의 `<Link>` 안에** 들어 있습니다.
> 그 안에 버튼이나 다른 링크를 넣으면 두 가지가 한꺼번에 터집니다.
>
> - 좋아요를 누르면 **좋아요도 되고 상세 페이지로 이동도** 됩니다
> - 작성자 링크는 `<a>` 안의 `<a>` 가 되어 **브라우저가 마음대로 해석**합니다
>
> **먼저 구조를 바꾸고 시작하세요.** 링크를 카드 전체가 아니라 "덮개" 로 만드는 방법입니다.
>
> ```tsx
> <article className="relative ...">      {/* relative 가 핵심 */}
>   {/* 카드 전체를 덮는 투명 링크 — 맨 아래 층 */}
>   <Link href={`/action/${action.id}`} className="absolute inset-0 z-0">
>     <span className="sr-only">{action.title}</span>
>   </Link>
>
>   {/* 내용은 링크 위에. 버튼·링크에는 relative z-10 을 준다 */}
>   <div className="relative z-10 pointer-events-none">
>     ...제목·설명...
>     <div className="pointer-events-auto flex gap-2">
>       <LikeButton actionId={action.id}
>                   initialLiked={action.likedByMe}
>                   initialCount={action.likeCount} />
>       <SaveButton actionId={action.id}
>                   initialSaved={action.savedByMe}
>                   initialCount={action.saveCount} />
>       <Link href={`/user/${action.owner.id}`}>@{action.owner.nickname}</Link>
>     </div>
>   </div>
> </article>
> ```
>
> `pointer-events-none` 으로 내용은 클릭을 통과시키고, 실제로 눌러야 하는 것에만
> `pointer-events-auto` 를 줍니다. **공유 버튼은 카드에 넣지 마세요** — 공유는 화면 이동이라
> 덮개 링크와 또 부딪힙니다. 상세 화면에만 두는 편이 안전합니다.

   QuotaProgress 의 getQuotaState 호출부도 바꾸지 않는다. 마크업과 className 만 바꾼다.

9. 서버 컴포넌트가 기본이다. 'use client' 는 훅·이벤트·브라우저 API 가
   필요할 때만 쓴다. 데이터 조회는 서버에서 하고 버튼만 클라이언트로 뺀다.

10. 목록 화면에는 빈 상태(EmptyState)를 반드시 넣는다. 다음 행동 버튼을 함께 준다.

11. 사용자에게 보이는 문구와 코드 주석은 한국어로 쓴다.

12. 홈과 액션 상세는 비회원도 볼 수 있다. user 가 null 일 수 있으므로
    user!.id 처럼 강제 단언하지 않는다. user?.id ?? null 로 넘긴다.

13. 새 파일·새 쿼리·새 상수를 만들기 전에, 이미 있는 것을 먼저 찾아 쓴다.
